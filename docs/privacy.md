# Приватность данных

## Что запрещено коммитить
- Токены, ключи, пароли, секреты.
- Персональные данные пользователей.
- Локальные дампы логов с чувствительной информацией.

## Обработка данных
- Хранить только минимально необходимые данные.
- В аудит писать безопасные метаданные.
- Не передавать чувствительные данные в SignalR payload.

## Удаление данных
- Временные и отладочные данные должны иметь ограниченный срок хранения.
