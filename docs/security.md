# Безопасность

## Базовые меры
- JWT-аутентификация с HMAC ключом.
- Ролевая авторизация: `Operator`, `Admin`.
- Белый список команд (allowlist), без raw-shell endpoint.
- Rate limiting для API.
- Аудит событий выполнения команд.

## Обращение с секретами
- Секреты не хранятся в репозитории.
- Используйте переменные окружения (`Jwt__Secret`, и т.д.).
- Локальные конфиги с секретами добавляйте в игнор.

## Требования к логам
- Не логировать токены, пароли, персональные данные.
- Логировать только безопасные метаданные.
